How to use this hub 🧠

1. Watch the Movie 🎬
Open a chapter and read its Memory Movie. Close your eyes and replay the pictures — each image is a point.
2. Test yourself 🃏
Flip the flashcards (or import the Cards file into Anki). Say the answer out loud before flipping.
3. Rehearse ✏️
Do the 3 practice questions on paper, then reveal the model answers. Print the PDF for offline revision.
